# RISC-V-SIMULATOR

Overview
This project is a RISC-V simulator that lets you write, run, and test RISC-V assembly code. It has a simple interface and works in two ways: a fast simulation and a hardware simulation that shows waveforms.

Features
1. Write and run RISC-V assembly code
2. Two ways to run code: fast simulation and hardware simulation
3. Shows results and waveforms
4. Includes examples like adding numbers, calculating factorial, and more
5. Easy to use interface

How It Works
1. Write RISC-V code in the interface
2. Choose to run it fast or check hardware simulation
3. See results or waveforms

Examples
- Adding two numbers
- Calculating factorial
- Summing an array
- Bitwise operations

Setup
1. Download the project
2. Install what's needed
3. Run the interface

Usage
1. Write or choose an example
2. Click "Run" for fast simulation or "Hardware Sim" for waveforms
3. Check results
